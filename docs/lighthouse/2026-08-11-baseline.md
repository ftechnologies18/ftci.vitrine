## Comment regénérer ces audits

```bash
# Prérequis : Chrome/Chromium installé
export CHROME_PATH="/path/to/chrome"

# Audit home (mobile)
lighthouse https://ftci.fr/ \
  --output=json \
  --output-path=/tmp/home.json \
  --only-categories=performance,seo,accessibility,best-practices \
  --throttling-method=simulate \
  --chrome-flags="--headless --no-sandbox --disable-gpu --disable-dev-shm-usage --disable-setuid-sandbox --single-process"
```

Pour visualiser un rapport JSON : [Lighthouse Report Viewer](https://googlechrome.github.io/lighthouse/viewer/).
