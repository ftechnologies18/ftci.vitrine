## Gains mesurés

### Lot 7 — Font fallback metrics (CLS fix)

- CLS Home : **0.051 → 0.007** (−86%)
- Technique : `@font-face` fallback avec `size-adjust`, `ascent-override`,
  `descent-override` calibrés pour Poppins/Inter via Arial local
- Le navigateur utilise le fallback instantanément (pas de blocage réseau),
  puis swap vers la web font sans que la hauteur des lignes ne change

### Lot 8 — CSP fix (Best Practices)

- `errors-in-console` ✅ résolu (beacon.min.js Cloudflare Insights autorisé)
- `inspector-issues` ✅ résolu (même CSP issue)
- Best Practices : **73 → 81** (+8 points)
- Reste : `deprecations` (3 APIs dépréciées du runtime Cloudflare Workers/Chrome
  — pas actionnable côté site, signal pour Cloudflare/Chrome)

## Note sur le CLS=1 du mode "simulate"

L'audit Lot 6 (mode `simulate`) rapportait CLS=1 sur la home. L'audit Lot 7
(mode `devtools`, mesures réelles) montre que le CLS réel était **0.051**
(acceptable, < 0.1 = bon). Le mode `simulate` applique un facteur multiplicatif
qui surévalue les petits shifts. Après le fix, le CLS réel est **0.007**
(excellent).
